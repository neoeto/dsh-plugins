# dsh-d2-diagram

A DeepSeek Harness web plugin that displays D2 diagrams generated by the
`d2_render` tool inline in the conversation page.

## How it works

- The host-side `d2_render` tool does the generation: it renders D2 source to
  SVG and publishes it at `/plugins/dsh-d2-diagram/svg/<id>` (native host
  capability; this plugin does not reimplement it).
- This package provides the client half: it registers the `d2_render` key of
  `tool.call.toolview`, parses the `SVG:` reference out of the tool result,
  and draws the diagram inside the tool card, with:
  - Zoom: mouse wheel (anchored at the cursor), + / − buttons (100%–400%),
    double-click to reset. Zoom changes the `<img>` layout width, so the
    browser re-rasterizes the SVG vector at every new size — crisp at any
    zoom level.
  - Pan: press and drag (when zoomed past 100%), clamped to the diagram
    bounds.
  - Show / hide the D2 source.
  - Copy the D2 code.
  - Download the SVG.
  - Open the SVG in a new tab.

## Mounting

`dsh-d2-diagram` is declared as a bundle in a profile (e.g.
`~/.dsh/profiles/web`):

```jsonc
// package.json
{
  "dependencies": {
    "dsh-d2-diagram": "link:/path/to/dsh-plugins/dsh-d2-diagram"
  },
  "dsh": {
    "profile": {
      "bundles": ["@deepseek-ai/dsh-base", "@deepseek-ai/dsh-web-app", "dsh-d2-diagram"]
    }
  }
}
```

`lib/client.js` is served directly by the harness client-modules service at
`/plugins/dsh-d2-diagram/client.js` — no build step required; refresh the page
after editing.

## Display contract

The `d2_render` tool result text contains:

```
Rendered d2 diagram to 242×375px (theme "default", layout "dagre"). …
SVG: /plugins/dsh-d2-diagram/svg/<id>
```

The card extracts the size / theme / layout information and the SVG path from
it, then renders the diagram.
